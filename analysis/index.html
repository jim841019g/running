比賽角色與檢核點

9/20永慶盃 10.5K — 夏訓驗收

用 T～半馬強度跑（4:50–4:55/km，約 51–52 分），心率壓 165 以下。能守住配速＝階段①成功；守不住也只是提醒你九月還是夏天，照表操課即可。不要全力，這場的成績沒有意義。

11 月三連賽：只有一場全力

11/7 舒跑杯半馬、11/15 電器杯 10K、11/22 南山——連三週比賽，全拚等於零場拚好。角色分工：舒跑杯＝MP 練習賽（全程鎖 5:10–5:13，練的是「壓住不衝」，正好治你 5K 前爆的老毛病，順便當一次有補給站的 21k long run）；電器杯＝T 刺激（4:40–4:45 八分力，當賽前磨刀）；南山＝唯一全力。

11/22南山半馬 1:40 — 全馬的期中考

1:40 ＝ 4:44/km，比 PB 快 71 秒，需要回到並略超一月的體能——按這份課表練到 11 月是合理的挑戰。Riegel 外推：1:40 → 全馬 ≈ 3:28，等於 3:40 有 12 分鐘的緩衝；就算只跑 1:43–1:44，3:40 仍然在手上。若掉到 1:48 以外，12 月目標下修到 3:45–3:50。賽道有坡的話（南山區域通常有），目標時間自己加 1–2 分鐘的坡稅再評估。

10/9–10/26出國：旅跑求生指南

行李箱第一件裝跑鞋。目標每週 20–25 km、不斷超過三天——你有前科：去年十月在加拿大照樣跑了 Banff 15k、今年四月在波爾多也出門跑了，這對你不是苦差事而是觀光方式。出發前（10/6–8）的 26k long run 是不可跳過的行前儀式；回國第一週時差下只跑 easy，別急著補課。旅行會吃掉原本 10 月的 30k 峰值——這筆帳由 11/1 的 26–28k 和 11/28 的 30k 一起還。

11/1 與 11/28long run 鏈：一環都不能掉

旅行後的 long run 鏈只剩三環：11/1 的 26–28k（回國收心課）→ 11/7 舒跑杯 21k @ MP（有補給站的品質長跑）→ 11/28–29 的 30k（南山賽後六天，大部分 easy＋尾端 8–10k @ 5:13，距全馬正好三週，是整份課表的壓艙石——南山跑完狀況再好也別加課）。最後一環尾段夾 MP 還能守住心率 < 160，3:40 就八成穩了。你所有半馬都是腿先到極限，這條鏈補的就是這個洞。

每週1–2 次下肢肌力

你本來就有重訓習慣，往「單腿硬舉、弓步、提踵」集中——2025 國道第 17 公里的 6:17 和 2026 國道的小腿痛，都是這裡能救的。

比賽日配速紀律

前 5 公里 5:20，不准快。你的 5K 測驗兩次都前衝後爆，但渣打 PB 證明你會遛氣球——用渣打模式跑，別用 5K 模式跑。3:40 兔子就是你的氣球。
